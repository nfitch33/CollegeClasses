Follow the instructions in [`lib/lib.ml`](lib/lib.ml).

## Notes

`ρ ⊢ e ⇓ v` means under environment rho `ρ`, expression `e` evaluates to value `v`

`Γ ⊢ e : τ` Gamma `Γ` entails `e` has type tau `τ`
