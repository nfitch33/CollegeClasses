My Project
doxygen-problem
  1. Study what argmax function in argmax.cpp does. You may run the program with your own input or use the example input/output section below.
  2. Configure doxygen, so it only generate HTML documentation.
  3. Modify Makefile, so that running make docs will create HTML documentation of the codebase.
  4. Using doxygen, document the argmax function. Your documentation must answer the following questions.
    • What is the acceptable type of the argument to the function? Is this function a template function? Use the appropriate doxygen special command to document this function's argument.
    • What are the meanings of the return values of this function? There are two possible types of return value, describe what each mean. Use the appropriate doxygen special command.
    • With just a sentence, briefly describe what the function does.

Submission

  1. Take a screenshot of the rendered HTML documentation (aka open the HTML file in the browser) of the argmax function.
  2. Add said screenshot to this repository in this folder.
  3. Make a commit (or commits) of your work and push it out to GitHub.

Appendix A - Rubric

100%

  • Students demonstrate the ability to configure doxygen for a specific requirement (only generate HTML documentation).
  • Students show that they can incoorporate Doxygen with GNU Make.
  • Students demonstrate the ability to use Doxygen's special commands to aid them in documenting the function.
  • Students show their analytical skill and able to deduce the behavior of a piece of code.
  • Students understand what get generated by Doxygen and show that they understand how to view this generated documentation.

50% to 90%

When student failed one or more of the items in the 100% category.

0%

When students failed all of the items in the 100% category. Students may also get this score when any or all of the items cannot be verified (e.g. forget to push commits to GitHub).
