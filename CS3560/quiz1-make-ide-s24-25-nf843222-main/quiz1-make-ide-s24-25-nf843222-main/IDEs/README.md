# Experiment with different IDEs

1. Experiment with any of the IDEs listed at: https://github.com/OU-CS3560/examples/tree/main/IDEs. Select one. Identify a feature to focus on. (This part you have done as an in class acticity. Feel free to propose another IDE or another feature of your choice. Ask for the TA's approval ahead of time.) 

2. Use the IDE of your choice for a meaningful session (actual coding session for CS3560, another class, or an actual project). 

3. Create a short report on the unique or innovative feature of your IDE that you identified. Include screenshots or short captured video. 

4. Create a pull request on this repository https://github.com/OU-CS3560/examples/tree/main/IDEs. Put all your material under a feature folder. For example, if you are exploring Visual Studio Code and using cline. Put everything under `https://github.com/OU-CS3560/examples/tree/main/IDEs/Visual Studio Code/cline`.
 
## Submission:
Submit your report, code, and any screenshots/videos to the subfolder in `IDEs` in the class `examples` repository through a pull request.

- A summary of the feature and your opinion regarding its pro/con;
- Code/project used in the example;
- Sceenshots or a short videos of the live session showcasing the feature.

Submit the links of your git classroom quiz repository and your pull request on Canvas.
